# Resource Monitor for Cthulhu

Resource Monitor is a Linux system monitoring tentacle for the
Cthulhu screen reader.

It provides spoken and braille reports of system resources,
including CPU, memory, disk, network activity, and uptime.

## Features

- CPU usage, including individual logical processors
- Physical and logical CPU core counts
- Memory and disk usage
- Network connection information and transfer rates
- IPv4 and IPv6 information
- VPN-aware network interface detection
- System uptime and Linux distribution information
- Background caching for responsive reports
- Clipboard copying

## Keyboard shortcuts

| Shortcut | Function |
| --- | --- |
| Alt+Cthulhu+1 | Complete system summary |
| Alt+Cthulhu+2 | CPU usage |
| Alt+Cthulhu+3 | Memory usage |
| Alt+Cthulhu+4 | Disk usage |
| Alt+Cthulhu+5 | Network information |
| Alt+Cthulhu+6 | System uptime |
| Alt+Cthulhu+7 | Linux distribution information |

Press a shortcut once to hear its report.

Press the same shortcut twice quickly to copy the report
to the clipboard.

## Requirements

- Linux
- Cthulhu with tentacle support
